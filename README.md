# Анализ алгоритмов сортировки
Данный проект представляет собой исследование временной сложности различных алгоритмов сортировки на различных типах входных данных. Реализовано 9 алгоритмов сортировки, проведены замеры времени их выполнения и построены регрессионные модели для анализа асимптотического поведения.

Реализованные алгоритмы сортировки:
- Сортировка вставками (Insertion Sort)
- Сортировка пузырьком (Bubble Sort)
- Сортировка выбором (Selection Sort)
- Сортировка слиянием (Merge Sort)
- Сортировка Шелла (Shell Sort) - три варианта:
- - Стандартная (последовательность Шелла)
- - С последовательностью Хиббарда
- - С последовательностью Пратта
- Быстрая сортировка (QuickSort)
- Пирамидальная сортировка (HeapSort)

# Методология исследования
Исследование проводилось на четырех типах массивов:
- Отсортированный массив - элементы расположены в возрастающем порядке
- Случайный массив - элементы генерируются случайным образом
- Обратно отсортированный массив - элементы расположены в убывающем порядке
- Почти отсортированный массив - 90% элементов упорядочены, 10% - случайные

# Размеры тестовых массивов
- Для алгоритмов с квадратичной сложностью: 4000-25000 элементов с шагом 5000
- Для алгоритмов с линейно-логарифмической сложностью: 100000-1000000 элементов с шагом 100000

# Методика измерений
Для каждого алгоритма и каждого размера массива измеряется время выполнения. Результаты визуализируются в виде точечных графиков с построением регрессионных кривых. Для каждого алгоритма и типа входных данных подбирается регрессионная модель, соответствующая теоретической временной сложности:
- O(n): линейная регрессия
- O(n²): квадратичная регрессия
- O(n log n): регрессия на n log n
- O(n^(3/2)): регрессия на n^(3/2)
- O(n log² n): регрессия на n log² n

# Основные функции
Алгоритмы сортировки: 9 функций, реализующих различные методы сортировки

`time_pass(n, random_arr)`: измерение времени выполнения алгоритма

`plot_results(sizes, times, n, case)`: визуализация результатов измерений

`regress_draw(sizes, times, n, case)`: построение регрессионных кривых

# Использование
Запуск основного скрипта выполняет полный цикл тестирования:
1. Тестирование на отсортированных массивах
2. Тестирование на случайных массивах
3. Тестирование на обратно отсортированных массивах
4. Тестирование на почти отсортированных массивах
Для каждого теста выводятся графики с результатами измерений и регрессионными кривыми.

# Научная значимость
Проект демонстрирует практическое соответствие теоретических оценок сложности алгоритмов их реальному поведению на различных типах входных данных, а также позволяет сравнить эффективность различных алгоритмов в одинаковых условиях.
